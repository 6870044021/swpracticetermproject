## การสาธิต

เตรียมฐานข้อมูลทดสอบกับ admin ให้พร้อมก่อนเริ่ม ไม่บันทึก credentials จริงในสไลด์ เปิด API และ Postman โดยใช้ค่าจาก `postman/README.md`

1. รัน collection ที่จัดลำดับ request และเก็บ IDs/tokens อัตโนมัติ
2. เปิดตัวอย่างจองสำเร็จ 201 เทียบกับการจองทับเวลา 409
3. เปิดตัวอย่างผู้ใช้ B อ่านการจองหรือโน้ตของ A ไม่ได้
4. เปิดตัวอย่าง anonymous review ที่ไม่มี user identifier และกรองด้วย `includeAnonymous=false`
5. เปิดสรุปผล Runner/Newman จริง ถ้าตัวเลขในสไลด์ไม่ตรงรอบล่าสุดให้อ้างอิงรายงานล่าสุด

อย่าใช้ข้อความในสไลด์แทนการ demo ประกาศกำหนดให้ demo จากโปรแกรมจริง หาก Runner ใช้เวลาเกินช่วงสาธิต ให้เริ่มรันก่อนเข้าหัวข้อทดสอบ แล้วเปิดผลเมื่อจบ
